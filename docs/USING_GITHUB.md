# Using this repository

[Back to the project](../README.md)

## The few terms you need

| Term | Meaning in this project |
| --- | --- |
| Repository, or “repo” | The project folder hosted on GitHub: `Princess-Otegbulu-Projects`. |
| Branch | A separate line of saved changes. Your original uploaded work was on `part-2`; GitHub opens `main` by default. |
| README | The front-page explanation displayed below the file list. |
| Commit | A saved change with a short description. GitHub keeps it in the project's history. |
| Pull request | A page for reviewing proposed changes from one branch before adding them to another. |
| Merge | Combining changes from one branch into another. |

## Find your CSULA work

Open the [repository home page](https://github.com/Princess-O1633/Princess-Otegbulu-Projects). The default `main` branch contains the CSULA files and a README with links to the scripts, images, and spreadsheets.

Use the [project map](PROJECT_MAP.md) to understand the files. The original `part-2` branch remains available through the branch menu above the file list.

## Make a small text edit

1. Open the file you want to edit.
2. Click the pencil icon.
3. Make the edit.
4. Click **Commit changes** and write a short description, such as “Clarify the project aim.”

For code changes you want to review first, choose a new branch when saving and open a pull request. Editing the README does not change your Python scripts.

## Add files from your computer

1. Open the destination folder in the repository.
2. Choose **Add file → Upload files**.
3. Add the files, then commit with a short description of what you added.

This repository is public. Add only material you intend to make public. GitHub does not automatically copy later changes from your computer; they must be uploaded or pushed separately.

## Keep research versions understandable

When identifying the analysis used for a result, record the script, input files, settings, and corresponding output. Preserve earlier versions in history rather than relying on names such as `final2.py`.

The first organization pass brings the existing `part-2` files into `main` and adds navigation. It preserves the original scripts, images, spreadsheets, and paths.
